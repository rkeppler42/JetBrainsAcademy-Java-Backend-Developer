# 🛒 My First Project with Java

A beginner-friendly console application developed as part of the **Hyperskill Java Backend Developer (Spring Boot) course**.

The project begins with a simple product catalog for a small shop and gradually evolves into a basic net income calculator. Each stage introduces new functionality while reinforcing fundamental Java concepts.

---

## 🚀 Project Progress

- [x] **Stage 1** — Print the Prices
- [x] **Stage 2** — Measure the Total Income
- [x] **Stage 3** — Calculate net income

---

## 📚 About the Stages

The application is developed incrementally. Each stage builds upon the previous implementation, adding new requirements and gradually transforming a basic console program into a shop income calculator.

---

<details>
<summary><strong>📌 Stage 1 — Print the Prices</strong></summary>

### 📝 Description

The first version of the application presents the catalog of a small corner shop.

At this stage, the program does not receive user input or perform calculations. Its only responsibility is to display the available products and their respective prices in the required format.

### 🎯 Objectives

1. Display a heading for the product price list;
2. Print the name and price of each available item;
3. Preserve the required capitalization, spacing, and order of the output.

### 💡 Expected Output

```text
Prices:
Bubblegum: $2
Toffee: $0.2
Ice cream: $5
Milk chocolate: $4
Doughnut: $2.5
Pancake: $3.2
```

</details>

<details>
<summary><strong>📌 Stage 2 — Measure the Total Income</strong></summary>

### 📝 Description

After the shop's first month of operation, the application is updated to produce a simple earnings report.

Instead of displaying product prices, the program now shows how much revenue each item generated during the month. It then adds these values together and displays the shop's total income.

### 🎯 Objectives

1. Display a heading for the earnings report;
2. Print the revenue generated by each product;
3. Store or represent the individual earnings as numeric values;
4. Calculate the total income by adding all product earnings;
5. Display the final result using the required format.

### 📊 Earnings Data

| Product        | Earned Amount |
| -------------- | ------------: |
| Bubblegum      |          $202 |
| Toffee         |          $118 |
| Ice cream      |         $2250 |
| Milk chocolate |         $1680 |
| Doughnut       |         $1075 |
| Pancake        |           $80 |

### 💡 Expected Output

```text

Bubblegum: $202
```

<details>
<summary><strong>📌 Stage 3 — Calculate the Net Income</strong></summary>

### 📝 Description

The final version turns the earnings report into a full profitability summary.

Besides showing what each product brought in, the program now reads two expense values typed by the user — payroll and everything else — and subtracts them from the gross total, revealing how much the shop actually kept.

All previous behaviour stays untouched; this stage only extends it.

### 🎯 Objectives

1. Keep printing the product names, their individual earnings and the gross total, exactly as before;
2. Prompt for payroll costs using the `Staff expenses:` label and read the value entered;
3. Prompt for the remaining costs using the `Other expenses:` label and read that value as well;
4. Subtract both amounts from the gross income;
5. Print the result using the `Net income: $<value>` format.

## ▶️ How to Run

Make sure a Java Development Kit is installed.

Compile the program:

```bash
javac Main.java
```

Run the compiled program:

```bash
java Main
```
